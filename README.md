# Taskromancer — десктопна версія для Windows

## Як отримати інсталятор (перший раз)

1. Розпакуй архів `taskromancer-desktop.zip` на комп’ютері.
2. Відкрий свій репозиторій на github.com.
3. Натисни **Add file → Upload files**.
4. Відкрий розпаковану папку і перетягни у вікно браузера **весь її вміст**: папки `.github`, `src`, `src-tauri` і файли `package.json`, `package-lock.json`, `.gitignore`, `README.md`. Перетягувати треба вміст, а не саму папку `taskromancer-desktop`.
5. Унизу натисни зелену кнопку **Commit changes**.
6. Перейди на вкладку **Actions**. Там з’явиться збірка «Build Windows installer» з жовтим кружечком. Вона триває приблизно 10–20 хвилин (перша найдовша).
7. Коли кружечок стане зеленою галочкою, відкрий на головній сторінці репозиторію праворуч розділ **Releases** → **Taskromancer v1.0.0** і скачай файл `Taskromancer_1.0.0_x64-setup.exe`.
8. Запусти його. Якщо Windows покаже синє вікно «Windows protected your PC», натисни **More info → Run anyway**. Це тому, що інсталятор не підписаний платним сертифікатом.

### Якщо після завантаження немає вкладки зі збіркою
Іноді браузер не завантажує папку `.github`. Тоді:
1. **Add file → Create new file**.
2. У полі назви введи `.github/workflows/build-windows.yml` (слеші створять папки самі).
3. Встав увесь текст із файлу `.github/workflows/build-windows.yml` з архіву і натисни **Commit changes**.

### Якщо збірка стала червоною
Відкрий її, натисни на червоний крок, скопіюй останні рядки помилки і надішли мені.

## Перенести дані з веб-версії
1. У веб-версії: шестерня → **Save backup (JSON)**.
2. У десктопній: шестерня → **Load backup…** і обери цей файл.

Під час першого запуску десктопна версія показує демо-дані, щоб було видно, як усе працює. Резервна копія їх замінить, або їх можна стерти кнопкою **Erase everything**.

## Де лежать дані
Шестерня → **Open data folder**. Там файл `data.json` і папка `backups` з копією за кожен із останніх 14 днів.

## Оновлення
Коли я надсилатиму нову версію, достатньо завантажити змінені файли тим самим способом (**Add file → Upload files**, з заміною). Збірка запуститься сама, а новий інсталятор з’явиться в **Releases**. Встанови його поверх старого, дані збережуться.

Збірку можна запустити й вручну: **Actions → Build Windows installer → Run workflow**.
